    Right where you review

    A funnel button appears next to GitHub's own "Filter files". One click, and generated code, lock files and snapshots leave the diff and the file tree.

    Know before you switch

    Every shortcut tells you how many files it would hide in the pull request in front of you. No guessing, no surprises.

    Made for your stack

    Go, C# and Flutter work out of the box. Add any language with your own patterns, or let your AI assistant write them: one click copies a ready prompt for your repository.

    Your code stays yours

    It runs only on github.com, reads nothing but file names, and sends nothing anywhere. No account, no analytics, no network requests.
