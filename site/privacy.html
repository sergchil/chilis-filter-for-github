Privacy policy

Last updated 1 October 2026

Chili's Filter for GitHub does not collect, store, sell or share any personal data.

What the extension reads

It runs only on github.com pages. On a pull request it reads the names of the changed files, so it can hide the ones that match your shortcuts. This happens in your browser and nothing is sent anywhere.

What the extension saves

Your shortcuts, languages and theme are saved in Chrome's own storage (chrome.storage.sync and chrome.storage.local). If you turn on Chrome sync, Chrome copies them to your other browsers. The developer never sees them.

What the extension does not do

It makes no network requests, has no analytics or tracking, uses no remote code and needs no account.

Questions
